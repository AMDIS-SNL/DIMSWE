# M1 state-location discovery provenance

These two records preserve the stopped 2026-08-28 feature-sufficiency study
that exposed the direct-regression state-location mismatch. In their original
wording, `M1` means the historical boundary-state objective now called
**M1-X**. The audit established that M1-X samples `X*`, while the moist law is
called after the timestep prefix at `Y*=P(X*)`.

The feature-sufficiency study itself did not train a model and is not a
canonical experiment. Its premise was retired after source tracing confirmed
that the deployed feature vector is already `(h, S, Qv, Qc, B)`. Its enduring
value is the state-location finding that motivated the separately completed
M1-Y campaign.

- `M1_STATE_LOCATION_AUDIT.md`: source-level X-versus-Y audit.
- `STUDY_STOP_REPORT.md`: explicit stop record; no feature study was run.

The files above are retained byte-for-byte. This README supplies the current
objective vocabulary without rewriting their historical contents.
