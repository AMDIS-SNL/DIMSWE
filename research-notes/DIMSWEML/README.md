# DIMSWE+ML technical research record

This directory contains the current synthesized technical research record for
the DIMSWE learned-physics study. It records the investigation's motivation,
methods, objectives, results, and interpretation; it is not presented as a
publication manuscript.

- `DIMSWEML.pdf` is the compiled document intended for reading.
- `DIMSWEML.tex` and `DIMSWEML.bib` are the editable source.
- The PNG files in this same directory are the figure assets referenced by the
  TeX source. The flat layout is intentional.

The 24 PNGs are byte-identical convenience copies of canonical assets already
retained under `postprocessing/ground_truth_figures_20260829/`,
`postprocessing/ml_results_20260829/`, and
`postprocessing/deployed_hybrid_dynamics_20260830/`. This self-contained
research-record package is not the authoritative provenance store.

Canonical implementation, frozen experiment evidence, postprocessing, and
artifact provenance remain in `dimswe/`, `external-results/`,
`postprocessing/`, `docs/`, `CANONICAL_EXPERIMENTS.md`, and
`REPRODUCING_RESULTS.md` in the repository root.
